1. logical
&&: and
||: or
!: not

2. numbers
-eq: equal
-ne: not equal
-lt: less
-le: less or equal
-gt: greater
-ge: greater or equal
+, -, \*, /, % have the usual definitions

3. String
=: equal
!=: not equal
<: less (ASCII)
\>: greater (ASCII)

4. files
-e: exists
-d: directory exists
-f: regular
-s: not empty
